# 屿生代 · 项目工作台

基于飞书多维表格业务逻辑的本地 Web 系统。Python 标准库 + SQLite + 原生 JavaScript，无需安装第三方依赖，无需 Node 构建。

## 启动

需要 Python 3.10 或以上版本。在项目目录执行：

```bash
python3 -m app.server
```

浏览器访问 **http://127.0.0.1:8765**。首次启动自动建立 14 张业务表的空库。关闭终端服务后网页不可用，再次运行命令即可继续；数据保存在 `data/isleon.sqlite3`。

自定义端口和数据库：

```bash
python3 -m app.server --port 8766 --db data/another.sqlite3
```

## 导入本地 .base 导出文件

在首次启动之前导入；已存在的数据库不会被覆盖：

```bash
python3 scripts/import_base.py '你的文件.base'
python3 -m app.server
```

若已启动建立空库，可导入到新数据库，再指定该数据库启动：

```bash
python3 scripts/import_base.py '你的文件.base' --db data/imported.sqlite3
python3 -m app.server --db data/imported.sqlite3
```

导入器解压 gzipSnapshot，按表 ID 和记录 ID 合并重复快照，解析字段自身的单选选项及跨表动态选项。**密码、证件、银行账户、手机号、邮箱等字段不导入；花名册仅导入工作管理所需的允许字段，薪酬和私密人事资料不导入。** `.base` 原文件保持不变。

## 功能

- 工作台：项目概览、制作任务、待审核交付和逾期任务。
- 项目总控：列表、卡片、资产／生成／后期进度，查看项目下的任务。
- 任务排期：搜索、负责人／状态筛选、分页和状态看板。
- 交付审核：版本、提交人、审核人、交付路径、意见、自动定稿时间。
- 作品库、商务合作、发行日历、赛事台账：列表及记录编辑。
- 团队与资源：花名册、平台账号的业务信息、招聘。
- 历史归档：历史任务及审核记录只读。
- SQLite 持久化、修订号冲突检查、变更审计、JSON 导出备份。

点击记录可打开详情抽屉并编辑。人员和多选字段使用顿号 `、` 分隔。新建项目可直接输入新名称；项目名称用于原表的跨表匹配，已有任务的项目暂不允许直接改名。没有设置删除入口，避免误删关联记录。

## 规则与范围

详细规则见 [业务逻辑说明](docs/business-logic.md)。当前是**本地单机版**，只监听 `127.0.0.1`；不提供登录、多人角色权限或远程部署。不会实时同步飞书，也不会执行飞书消息通知、自动化、NAS 上传或文件移动。路径仅作为文本保存。原表各视图的筛选、权限和仪表盘配置没有逐项复刻。

表结构可供独立运行。仓库中不包含原始 `.base`、真实业务记录、人员名单、SQLite 数据库、运行日志或备份。公开仓库的空库选项不包含项目名称、账号名称、人员名称等实际业务选项。

## 备份与恢复

停止服务后备份 `data/isleon.sqlite3` 即可保留业务数据及审计记录；恢复时将备份放入 `data/`，通过 `--db` 指定它启动。页面“导出备份”生成业务 JSON，适合离线查阅和数据迁移，目前没有 JSON 导入界面。请将备份保存在本地，勿提交到 Git。

## 验证

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

集成测试在临时数据库和临时本机端口运行，不修改本地业务数据库。覆盖审核与进度联动、不同提交人的匹配隔离、返修、发行状态、重复快照与选项解码、敏感字段过滤、持久化、修改冲突、历史只读及跨站写入拒绝。

## 代码

- `app/importer.py`：本地 Base 解析、动态选项和敏感字段过滤。
- `app/logic.py`：业务计算。
- `app/db.py`：SQLite 存储与审计。
- `app/server.py`：本地 HTTP 服务与写入校验。
- `app/schema.json`：无业务记录的空库结构。
- `static/`：页面、样式与交互。
