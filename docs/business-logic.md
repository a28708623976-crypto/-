# 业务逻辑与迁移边界

## 数据关系

作品库／商务合作 → 项目总控 → 制作任务 → 版本交付与审核 → 项目进度汇总；社媒账号 → 发行排期。赛事、团队与平台资源辅助各环节。

原表大量关联通过单选名称匹配，而非关系型外键。当前版本保留这些匹配语义，没有根据相似名称自动合并记录。

## 审核与任务

交付日志依据“提交任务 = 任务详情”且“提交人与负责人有交集”推导项目和集数，再依项目、集数推导任务类型。

满足提交人、提交任务、项目、路径、版本、审核人均非空时：

| 审核意见 | 结果 |
| --- | --- |
| 空 | 待审核 |
| 精确等于 `✅` | 定稿 |
| 其他文本 | 返修 |

信息不完整的历史导入记录保留空审核结果，并在页面提示完善信息。新建交付须完整填写必要字段。项目匹配为空或有多个候选时，禁止写入定稿。

任务实际完成时间取相同项目和任务详情、定稿、且提交人包含任务负责人的日志中最大的定稿时间。返修次数统计同项目和任务详情下的返修日志，保留原表未按负责人过滤返修次数的口径。

无负责人 → 待分配；有负责人且完成时间非空 → 已完成；否则制作中。已完成优先于逾期判断。逾期按上海时区当天零点是否晚于截止时间判断；缺截止时间不判逾期。交付时效差为截止时间减完成时间的完整天数。

导入的定稿时间来自原文件；网页首次改为定稿时使用服务端当前时间，撤销定稿则清空该条日志定稿时间。修改历史版本意见会影响原公式统计，当前没有额外的“只取最新版本”规则。

## 项目进度

- 资产任务：全剧资产（含人物、场景、道具）、人物资产、场景资产、道具资产。
- 生成任务：AI生成。
- 后期任务：后期剪辑。
- 各阶段进度 = 已完成任务数 / 阶段总任务数。
- 总进度 = 三类已完成任务数合计 / 三类总任务数合计。
- 分母为零时结果为零。剧本围读、分镜表、发行任务、独立全程等不计入上述三类分母，与原公式一致。

## 作品及商务

作品库按照基础信息完整、稿件、世界框架、人物小传、台词本、改编剧本逐步推导进度。载体为剧本时，完成阶段不强制要求改编剧本。

商务依据基础作品信息、合作方式、支付方式／金额或利润分红比例、合同编号和合同路径推导撰稿、确认合作、已完成签署阶段。

## 发行

无实际发布时间 → 待发布；等于计划 → ✅；早于计划 → 提前发布✅；晚于计划 → 延期发布❌。未填计划但已有实际时间时，沿用原公式的时间比较口径。此处为记录与统计，不代表自动向平台发布。

## 未迁移能力

飞书实时权限、工作流、消息卡片、自动通知、表单分享、仪表盘原布局及 NAS 文件自动处理未接入。薪酬相关字段没有导入，因此不提供原薪酬成本看板。历史表保持只读；日期、跨表和核心进度公式由应用计算，不运行任意飞书公式表达式。
